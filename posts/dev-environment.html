从零搭建个人网站（二）：准备开发环境

2026 年 10 月 20 日 建站 工具

做纯静态网站，需要的东西比想象中少：一个编辑器、一个浏览器、一个 Git。Node.js 和 IDEA 等到做动态版时再装。

安装 VS Code

在官网下载 Windows 版的 User Installer。安装时"其他任务"那一页建议全部勾选，尤其是：

  • 添加到 PATH：以后在命令行输入 code 就能打开
  • 通过 Code 打开：右键文件夹直接用 VS Code 打开

装好后再装一个扩展 Live Server：在 HTML 文件上右键选 "Open with Live Server"，浏览器会打开页面，以后每次保存都自动刷新。

安装 Git

安装向导大部分保持默认，只改两处：

  1. 默认编辑器选 Visual Studio Code
  2. 初始分支名选 Override，填 main

确认安装成功

打开 PowerShell，输入下面两条命令，都能显示版本号就说明成功了：

code --version
git --version

如果提示"无法识别"，关掉 PowerShell 重新打开再试，刚装好的软件只有新开的窗口才能识别。

告诉 Git 你是谁

Git 每次提交都会记录作者，第一次使用要先设置名字和邮箱：

git config --global user.name "Everett"
git config --global user.email "you@example.com"

邮箱最好和 GitHub 账号用同一个，这样提交记录能关联到你的账号。
